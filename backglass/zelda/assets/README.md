# Asset provenance

Created for this project on 2026-10-18 using the built-in imagegen tool:

- `hyrule.png`: Ocarina-inspired dawn landscape, castle, Death Mountain, forest arch.
- `map.png`: illustrated Hyrule atlas with six destinations and no baked-in labels.
- `temple.png`: Temple of Time, altar, sword and golden relics.
- `sword.png`: new Master Sword close-up for the cinematic attract sequence.
- `dark.png`: ruined castle, eclipse, hero and distant dark sorcerer.

All five PNGs are unmodified generated outputs, copied into the project. Their
painterly emerald / antique-gold direction is shared across all screens. No
reference screenshots or extracted game assets were used. Each original is
1672×941; Godot scales and gently pans it on the 1920×1080 canvas.

`move.wav`, `confirm.wav`, `award.wav`, `dark.wav`, `ambient.wav` and `attract.wav` are original
mathematically synthesized tones, generated by `../../utils/generate_audio.py`.
No sampled soundtrack material is used. Decorative geometry, emblems, fireflies,
light rays, rupees and fairy trails are generated by `../backglass.gd` at runtime.
Cinematics are real-time Godot sequences, not AI-generated video files.

`attract.wav` is an original 44-second synthesized score with chord changes aligned
to the seven shots in `../attract.gd`. The film uses real-time camera movement and
composited effects rather than a prerecorded video.
