Build your own

Your game. Your rules.

Pinball CTL is software for building and running a homebrew pinball machine. It runs on a Raspberry Pi and works with an ESP32-S3 controller to connect switches, coils and lights. Use your browser to configure hardware, create game rules and scoring, and add lighting, sound and displays. Whether you're starting a new build or developing an existing machine, Pinball CTL brings the tools together in one place.

How it works

Three parts.
One pinball controller.

Pinball CTL uses a Raspberry Pi, an ESP32-S3 and a browser-based interface. Each has a different job, working together to run your machine.

[[art:platform:0]]Runs your game

Raspberry Pi

Runs the Pinball CTL software, including game rules, scoring, sound, displays and the web interface.

[[art:platform:1]]Controls your hardware

ESP32-S3

Reads switches, controls supported outputs and handles time-critical hardware responses. It also enforces configured coil safety limits.

[[art:platform:2]]Where you build

Your browser

Configure hardware, create game rules, design lighting and manage your machine from a single interface.

Raspberry Pi + ESP32-S3

Built for real-time control.
Made for homebrew.

The Raspberry Pi runs your game software, scoring, sound and displays. The ESP32-S3 handles switches and supported real-time hardware responses, including coil safety limits. This separates the time-critical hardware control from the rest of your game software.
