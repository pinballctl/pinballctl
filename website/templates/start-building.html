Quick start

Ready for the terminal?

The essentials from the original quick start, together in one place.

  1. Flash Raspberry Pi OS (64-bit) using Raspberry Pi Imager.
  2. Boot your Pi and connect using SSH or a keyboard and monitor.
  3. Run these commands on the Pi to create a Python environment and install pinballCTL.
  4. Open http://<pi-ip>:8888 in your browser, replacing <pi-ip> with your Pi’s address.

Replace vX.Y.Z with a published release tag before running the install command.

Full installation guide & troubleshooting →
ON YOUR RASPBERRY PI · TERMINAL
sudo apt update
sudo apt install -y python3-venv python3-pip git
mkdir -p ~/pinballctl
cd ~/pinballctl
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install "git+https://github.com/pinballctl/pinballctl.git@vX.Y.Z"
pinballctl --version
pinballctl start
